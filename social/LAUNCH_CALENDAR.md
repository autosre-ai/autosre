## CONTENT GUIDELINES

### Twitter Best Practices
- Thread starters should hook in first tweet
- Use emojis strategically (🚀 ⚡ 🔧 🎯 ✅)
- Include visuals where possible
- End threads with CTA (link, follow, retweet)
- Optimal posting times: 9am, 12pm, 5pm EST

### LinkedIn Best Practices
- Professional tone but accessible
- Include relevant hashtags: #SRE #DevOps #Kubernetes #Automation
- Tag relevant companies/people when appropriate
- Use line breaks for readability
- Include clear CTAs

### Hashtags
Primary: #AutoSRE #SRE #DevOps
Secondary: #Kubernetes #K8s #CloudNative #Automation #IncidentResponse
Tertiary: #OpenSource #AI #ML #Observability
